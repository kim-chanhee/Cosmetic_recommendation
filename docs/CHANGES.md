# 파이프라인 수정 및 검증 내역

## 유지한 전체 구조

올리브영 리뷰 수집 → Komoran 전처리 → 사전 기반/TF-IDF 감성 분석 → KoBERT + SVD + 피부 필터 → 추천 표·그래프.

세 노트북 모두 단계별 Markdown 제목, 입력·출력 설명, 라벨·분모·평가 정책 설명, 함수 주석을 추가했습니다. 이전 실행 출력은 제거하고 수정된 코드를 처음부터 실행한 출력으로 교체했습니다.

## 파일별 수정

### 전처리 노트북

- 원본 12,347행 중 유효하지 않은 리뷰 30행, 중복 522행 제거: 최종 11,795행.
- 정제 텍스트·제품·작성자·날짜 기반 고유 `review_id` 생성.
- 피부 타입 보완 여부를 별도 컬럼으로 기록: 1,252행 보완, 결측 5,376행.
- 단어 합성 시 원본 리스트를 변경하지 않아 셀 재실행 안전성 개선.
- 한글 폰트의 실제 파일 경로를 사용하고 CSV 저장을 시각화보다 먼저 수행.
- 요약 JSON, 키워드 그래프, 워드클라우드 저장.

### 감성 분석 노트북

- 1=긍정, 0=부정으로 통일.
- macOS Alias를 공식 KNU 자료 기반 실제 UTF-8 사전으로 대체. 이전 사용자 확장 사전과 동일하지 않음.
- 사전의 형태소 충돌을 제외하고 미매칭/0점은 판단 불가 처리. 문장 전체의 부호를 뒤집는 규칙 제거.
- TF-IDF를 Pipeline 안에서 폴드별 학습하고 작성자 단위 5겹 검증 적용.
- 사전 결과는 비교용으로 보존하고, 추천에는 TF-IDF/Logistic Regression의 OOF 확률 사용.
- `sentiment_score = 2 * positive_probability - 1`을 리뷰 ID와 함께 저장.

### 추천 노트북

- ID 집합·중복·스키마·확률·라벨 정의를 검사한 1:1 병합.
- 평점 보정을 `clip(rating + 0.5 * sentiment_score, 1, 5)`로 변경.
- 리뷰별 모든 토큰을 조각 단위로 임베딩하고 패딩·특수 토큰을 제외해 평균. 제품별로 리뷰 벡터 집계.
- 모델 버전·전체 입력 기반 임베딩 캐시.
- Surprise 미설치 시 미관측 0점 행렬 대신 관측 평점만 학습하는 편향 포함 PyTorch 잠재요인 모델 사용.
- 같은 사용자·제품 반복 평점은 평균. 예상 평점은 1~5 범위로 제한.
- 피부 결측 조건 제외, 고민 분리, 알려진 정보만 분모에 포함, 최신 유효 프로필 사용.
- 후보 완화 이유 표시, 신규 사용자 인기순, 콘텐츠 없는 사용자 협업 추천, 동점 정렬 고정.
- 최종 표·Figure 3·Figure 4를 실제 함수 결과와 연결.
- 후보가 없으면 빈 CSV/빈 상태 그림을 출력해 과거 결과가 새 결과로 보이지 않게 처리.
- 사용자별 보류 평가와 인기순·평균 평점·협업·콘텐츠 비교 추가.

### 공통 및 보조 코드

- `code/common/project_utils.py`: 리뷰 ID·라벨·병합 검증 규칙.
- `code/05_시각화/plot_skin_ratio.py`: 고정 상품 목록을 제거하고 추천 CSV의 상품 순서와 점수 사용.
- `tests/test_pipeline.py`: 병합 순서·라벨 반전·중복 ID, 피부 결측/고민/날짜, 마스킹, 관측 MF, 중복 평점, 신규 사용자, 보류 분할, 정규화 등 11개 테스트.
- 노트북 자동 패키지 설치 제거. 전체 단계 의존성과 실행 가이드 갱신.

## 실행 검증

- 전처리·감성·추천 노트북 3개 모두 새 커널에서 순서대로 전체 실행 완료.
- 원본 리뷰 CSV는 수정 전 백업과 SHA-256 동일.
- 11,795개 리뷰의 ID가 전처리·감성·추천 입력에서 동일하며 중복 없음.
- 기본 사용자 `vwaaang`의 실제 추천 10개 생성. 기존 리뷰 제품 제외 확인.
- 그림의 제품·점수는 추천 CSV에서 생성. Figure 3 비율 합 1 검증.
- 회귀 테스트 11개 통과.
- 이번 실행은 Surprise 없이 `observed_mf` 구현을 사용. Surprise 경로는 이 환경에서 실행 검증하지 않음.

## 관측된 성능과 한계

### 감성

평점 4점 이상을 긍정으로 둔 사용자 단위 OOF 평가:

- 부정 F1: 0.3733
- 부정 재현율: 0.4640
- 부정 ROC-AUC: 0.8278
- 부정 Average Precision: 0.3099
- 사전 판단 가능 비율: 87.80%; 판단 가능한 리뷰에서 정확도 63.48%.

분할 방식이 이전 평가와 다르므로 이전 수치와 직접 비교해 개선율을 주장하지 않습니다. 감성 정답은 평점 기반 대리 라벨이고 출력 확률은 별도 확률 보정을 거치지 않았습니다.

### 추천

718명, 보류 리뷰 1,013개, 학습 리뷰 10,782개. 동일 피부 필터 후보를 사용했습니다.

| 방식 | Recall@10 | NDCG@10 |
|---|---:|---:|
| 인기순 | 0.8315 | 0.3365 |
| 평균 평점 | 0.5153 | 0.2740 |
| 협업 | 0.7006 | 0.2865 |
| 콘텐츠 | 0.7730 | 0.4829 |
| 하이브리드 | 0.7521 | 0.3398 |

후보 정답 포함률은 99.58%입니다. 하이브리드가 모든 기준에서 우수하지 않으며 가중치 0.5는 검증으로 선택한 최적값이 아닙니다. 평가값을 보고 같은 평가셋에 맞춰 가중치를 조정하지 않았습니다.

평가는 **감성 보정을 끈** 학습 데이터만으로 재학습합니다. 전체 평점으로 생성된 OOF 감성 확률이 보류 정답을 간접 전달하는 것을 막기 위한 것입니다. 감성까지 포함한 최종 모델의 효과는 별도 외부 분할에서 감성 모델까지 재학습해 검증해야 합니다. 분할은 사용자별 마지막 제품 보류이며 전역 시간순 검증은 아닙니다.

제품이 20개뿐이라 Top-10 지표는 상대적으로 높게 나올 수 있습니다. KoBERT 제품 유사도는 서로 가깝고 후보 내 정규화가 작은 차이를 확대할 수 있습니다. 피부 비율은 리뷰 작성자 구성 정보이며 효능 검증이 아닙니다. 작성자명은 안정적인 회원 ID가 아닐 수 있습니다.
